OCT News 24 — Starter website

Included: index.html (responsive Bengali news portal starter).

IMPORTANT:
- This is a starter/demo, not yet a live published website.
- The sample headlines and image placeholders must be replaced with verified news and licensed images.
- The submission form is a demo and does not securely store submissions. Its email button creates a mailto draft only; users must send it themselves. For real public use, connect a form provider or a secure backend and add spam protection.
- Do not publish user-submitted claims until they have been checked and approved.
- For YouTube videos, use official embed links and verify permission/rights before re-uploading any third-party content.

Free hosting path:
1. Create/sign in to GitHub and create a repository named oct-news24.
2. Upload index.html from this folder to the repository root.
3. In Cloudflare, open Workers & Pages > Create > Pages > Connect to Git.
4. Select the repository. For a plain HTML site, choose no framework; build command can be blank and output directory can be / (or follow current Cloudflare Pages UI instructions).
5. Deploy and use the provided pages.dev subdomain. You can connect a custom domain later, but domains typically cost money.
